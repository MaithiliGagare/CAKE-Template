# 🎂 Cake Website Template

A beautiful and responsive **Cake Website Template** designed using **HTML5, CSS3, and Bootstrap 5**. This project focuses on creating an attractive bakery and cake shop website with a clean layout and user-friendly design.

### ✨ Features

* 🎂 Attractive Home/Hero Section
* 🧁 Cake & Bakery Products Section
* 🍰 About Us Section
* ⭐ Special Offers / Featured Cakes
* 👩‍🍳 Services Section
* 📸 Gallery Section
* 📞 Contact Section
* 📱 Responsive Design
* 🎨 Clean and Modern UI
* 🧩 Bootstrap-Based Layout

### 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Bootstrap 5**

### 🎯 Purpose

This project was created to practice and demonstrate **frontend web development skills**, including responsive layouts, Bootstrap components, CSS styling, and modern website design.
